A tiny stack virtual machine for make.fun's tiny stack ISA: 32-bit wrapping integers, a 256-value stack, calls, 256 words of memory, input/output and all ten traps, in one dependency-free `main.ts`.

Run locally (Node 22+):

```sh
mkdir -p out
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
